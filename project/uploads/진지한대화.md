# 진지한 대화 서비스 기획안 (가제: 진지)  최종

> 경쟁 상대는 다른 대화 앱이 아니라 **유튜브**다. 유튜브가 이기는 이유는 준비된 화자, 정리된 논점, 조롱 없는 환경. 그걸 양방향으로 만드는 것이 목표.
> 

**한 줄 정의**: 주제와 태도가 검증된 사람과, 구조를 갖춘 진지한 대화를 하는 곳

---

# 1. 문제 정의

| 상황 | 현재 | 원인 |
| --- | --- | --- |
| 대면 단체모임 | 진지한 얘기 꺼내면 "이상한 애" 취급, 조롱 | 진지함 자체를 처벌하는 문화 |
| 소수 모임 | 꺼낼 수는 있으나 이어지지 않음 | 상대의 지식 부족 / 관심 부족 |
| 대안 | 유튜브 영상으로 만족 | 일방향, 갈증 해소 안 됨 |

---

# 2. 트랙 분리 (설계 대전제)

'진지함'은 두 종류이며, 같은 방에 넣으면 서로가 서로를 "왜 저래" 하게 된다. 매칭 단계에서 반드시 분리.

| 구분 | A. 깊은 이야기 | B. 지적 논의 |
| --- | --- | --- |
| 주제 | 죽음, 외로움, 후회, 삶의 의미 | 정치, 기술, 윤리, 경제 |
| 원하는 것 | 이해받기, 들어주기 | 반박받기, 검증받기 |
| 잘못 매칭 시 | 반박당하면 상처 | 공감만 받으면 시시함 |

**파생 라인 매핑**

- 진지한 대화 → A 트랙
- 진지한 토론 / 진지한 싸움 → B 트랙
- 진지한 결혼 → A+B를 모두 통과한 사람들의 상위 레이어

> **진지한 결혼**의 실제 세션 진행은 4장 '진지한 토론'의 참여자 구조(사회자 겸 심판 AI + 최소 2대2 + 관전자)를 그대로 재사용한다. 처음부터 1:1로 매칭하지 않고, 그룹으로 먼저 만나본 뒤 관심 있는 상대로 좁혀가는 방식 — 8장에서 요구하는 "파생되기 쉬운 구조"를 결혼 라인 자체가 증명한다.
> 

---

# 3. 온보딩 — 첫 진입 경험

정적인 안내문(약관식 텍스트) 대신 **AI가 진행하는 인터랙티브 튜토리얼**로 대체한다.

- 신규 사용자: AI를 상대로 짧은 모의 세션(질문 던지기, 인정 버튼 눌러보기, 발언권 규칙 체감)을 1~2턴 체험한 뒤 본 서비스로 진입.
- 기존/숙련 사용자: 즉시 **건너뛰기** 가능.
- 근거: 텍스트로 나열한 규칙은 읽지 않는다. 9장 AI 스파링의 "규칙을 말로 설명하지 않고 보여주기" 철학을 온보딩 단계에도 동일하게 적용 — 서비스 전체가 "규칙은 체감시킨다"는 원칙 하나로 일관된다.

# 4. 세션 구조 — 참여자 · 규칙 · 종료

## 4-1. 포맷별 참여자 역할

| 포맷 | 참여자 구성 |
| --- | --- |
| 진지한 대화 | 참여자(사람) 2명. 별도 사회자·관전자·방장 없이 1:1 매칭 즉시 시작 |
| 진지한 토론 | 사회자 겸 심판(AI), 참여자(사람 — 최소 2대2. 한쪽으로 의견이 쏠리거나 인원이 부족하면 AI가 해당 팀에 보충), 관전자, 방장 |
| 진지한 싸움 | 참여자(사람 2명, 명시적 합의로 성립), 관전자(승패 투표), 방장(초기 규칙 설정) |
| 진지한 결혼 | 사회자 겸 심판(AI), 참여자(사람 — 최소 2대2, 토론과 동일한 보충 규칙), 관전자, 방장. 그룹으로 먼저 만난 뒤 관심 상대와 1:1로 좁혀감 |

> 진지한 싸움만 AI 고정 심판 대신 관전자 투표를 유지한 이유: 8장에 이미 "승패 판정을 AI가 하지 않게 한다"는 원칙이 있고, 싸움은 개인 대 개인의 격돌이라 팀 보충(AI) 개념 자체가 성립하지 않는다.
> 

## 4-2. 방장의 규칙 설정 권한 (토론 · 결혼 · 싸움)

세션 시작 전, 방장이 최소한의 규칙을 직접 설정한다.

- 발언 순서 / 타이머
- 욕설 허용 여부 (기본 비허용, 방장이 완화 가능 — 단 6장의 조롱·인신공격 축은 방장 권한으로도 해제 불가)
- **손들기**: 원래 발언 순서가 아니지만 같은 팀 의견에 덧붙이거나 먼저 말하고 싶을 때 사용. 세션당 횟수 제한 있음(방장이 설정)

## 4-3. 진지한 대화 전용 — 답변완료 버튼 · 기한 설정

- **답변완료 버튼**: 상대의 말이 끊기지 않도록, 내 차례가 끝났음을 명시적으로 선언하는 버튼. 짧게 끝난 발언은 시간을 다 채우지 않고도 버튼으로 순서를 넘길 수 있다.
- **기한 설정**: 대화 주제에 일자를 정해, 비동기로 늘어지는 대화도 마감을 갖게 한다 (10장 콜드 스타트 대응의 비동기 텍스트 스레드와 연결).

## 4-4. 세션 종료 조건

| 포맷 | 종료 방식 |
| --- | --- |
| 진지한 대화 | 양측 클로징 완료 시 자동 종료 / 양측이 답변완료 버튼으로 조기 합의 종료 / 기한 도래 시 자동 마감 |
| 진지한 토론 | 정해진 타이머(오프닝-반박-클로징) 종료 시 / 방장의 조기 종료 제안에 참여자 과반 동의 시 |
| 진지한 싸움 | 사전 합의된 라운드·시간 종료 시 / 관전자 투표 판정 후 종료 — 일방 이탈은 기권패로 기록 |
| 진지한 결혼 | 그룹 세션은 진지한 토론과 동일한 종료 규칙 / 이후 1:1 전환분은 양측 합의 또는 무응답 기간 경과로 종료 |

## 4-5. 편성 매칭 — 유동성을 시간대에 모으기

실시간 매칭은 상시 오픈이 아니라 **정해진 시간대(편성표)**에만 연다 — 정규방송·주간 공개 콘텐츠처럼 정해진 시간에만 열어 유동성을 모은다.

- 트랙·주제별로 고정 시간대 배정 (예: 화 20시=B트랙 정치토론, 목 21시=A트랙 삶의의미 대화)
- 편성 30분 전 알림 발송, 대기실에서 카운트다운 — 기다리는 시간 자체를 기대감으로 전환 (정규방송·주간 공개 편성 문화와 동일한 메커니즘)
- 상시 매칭은 편성 시간대와 별도로, 유동성이 실제로 검증된 인기 트랙·시간대에 한해서만 점진적으로 개방
- 편성 시간 사이는 4-3의 **답변완료 버튼 + 기한 설정**을 쓰는 비동기 스레드가 기본으로 메운다 — 편성 시간은 축제, 그 사이는 잔잔하게 이어지는 스레드

# 5. 세션 준비 — AI 사전 브리핑

매칭 확정 후 시작 5분 전, 양쪽에게 동일한 1페이지 브리핑 발송.

- 핵심 용어 5개
- 쟁점 3개
- 대표적인 반대 입장 2개
- 주최자가 참고자료 링크 추가 가능

지식 격차를 없애진 못하지만 "무슨 말인지 몰라 끊기는" 상황은 대부분 차단. 브리핑 완독 여부가 곧 성의의 증거.

# 6. AI 모더레이션

서비스의 심장. 축을 4개로 나눠야 정밀도가 나온다.

| 축 | 예시 | 비고 |
| --- | --- | --- |
| 비속어 | 명시적 욕설 | 자동 탐지, 오탐 적음 |
| 존대 이탈 | "야", "그거 아니라니까" | 어미 분석, 한국어라 오히려 용이 |
| 인신공격 | "당신 논리가 틀렸다"(OK) vs "당신이 멍청하다"(NG) | 공격 대상이 주장인가 사람인가 |
| **조롱·비꼼** | "ㅋㅋ 그걸 왜 진지하게" | **진짜 차별점** |

> 네 번째가 핵심. "이상한 애 취급"은 욕설이 아니라 조롱의 형태로 온다. 욕만 거르는 서비스는 이미 많고, 그런 곳에서도 여전히 진지한 얘기를 못 한다. "진지충", "오글거린다", "갑자기 왜 이래" 류의 **진지함 자체를 처벌하는 발화**를 잡는 것이 이 앱의 존재 이유.
> 

## 경고 처리

1. **1차** — 본인에게만 조용히 표시. 타 참가자에게 비공개 (공개 망신은 방어적 태도를 유발해 대화를 더 망침)
2. **2차** — 발언권 30초 정지. 상대에겐 "잠시 정리 중"만 표시
3. **3차** — 세션 퇴장, 기록 반영

## 오탐 대비 (필수)

- 세션당 1회 이의제기 → 사후 검토 → 인정 시 기록 삭제
- AI가 억울한 판정을 내리는 순간 진짜 좋은 사용자부터 이탈
- **신고 기반은 최소화** — 의견이 다르다는 이유로 신고를 무기화하는 건 시간문제. AI 1차 판정 + 사후 인간 검토 구조로.

# 7. 평판 시스템 → 진지충(가제) 캐릭터 키우기

경고 횟수를 평판으로 쓰면 "안 걸리는 법"만 학습된다. **긍정 지표 중심**으로.

| 배지 | 조건 |
| --- | --- |
| 🎧 끝까지 들음 | 상대 발언 중 끼어들기 0회 |
| 🔄 **생각이 바뀜** | 클로징에서 입장 변화를 스스로 밝힘 |
| 🛡️ 스틸맨 | 상대 주장을 상대보다 잘 요약 |
| 📖 브리핑 완독 | 준비하고 옴 |

> **"생각이 바뀜"을 최고 등급 배지로 만드는 것이 핵심.** 온라인 토론이 지옥인 이유는 입장을 바꾸는 게 패배로 취급되기 때문. 그걸 명예로 뒤집는 순간 이 앱은 다른 어떤 서비스와도 다른 곳이 된다.
> 

## 7-1. 진지충 캐릭터 성장

알 → 애벌레 → 번데기 → 성충. 대화 횟수로 갈 수 있는 건 **번데기까지**. **성충이 되려면 '생각이 바뀜' 1회가 필요.** 변태(metamorphosis)가 곧 입장 변화 — 은유가 아니라 시스템. 100번 대화해도 한 번도 안 바꾼 사람은 애벌레다.

> "당신의 진지충은 아직 애벌레입니다. 한 번도 생각을 바꾼 적이 없거든요."
> 

성충의 날개 무늬는 다뤄온 주제 조합으로 결정된다. 결혼 라인 프로필은 사진이 아니라 이 날개가 대신한다.

**성체 이후 — 뇌절 진지충**: 성체를 성장의 끝이 아니라 시작으로 재정의한다. 알 → 애벌레 → 번데기 → 성충 → **초성충**(생각이 바뀜 누적 3회, 날개가 과장되게 화려해짐) → **전설의 진지충**(누적 10회, 왕관·후광 등 코미컬하게 과한 장식) → **"이 사람 실화냐" 티어**(극소수, 전용 칭호+프로필 이펙트). 상위 티어일수록 희귀해지는 수집 구조.

- **자랑 ≠ 조롱**: 본인이 자발적으로 티어를 노출하는 건 명예다. 타인이 그걸로 놀리는 건 여전히 6장 조롱 모더레이션 대상.
- **어뷰징 방지**: 상위 티어일수록 자기 선언만으로는 부족하고, 상대의 인정 버튼 또는 AI 사회자 코멘트로 함께 검증돼야 카운트된다.
- **순수 코스메틱**: 매칭 우선권 등 기능적 이득은 없다 — 프로필 프레임·칭호·이펙트 노출만.

## 7-2. 인정 버튼

"그건 맞네" 버튼, 세션당 3개. 내가 누르면 상대 캐릭터가 크고, **동시에 내 캐릭터도 큰다.** 크게 자라는 법은 이기는 게 아니라 인정받고 인정하는 것. AI 판정 0회라 편향 논란도 없고, 구현은 버튼 하나 + 카운터 하나. 3개 제한이 진짜 장치야 — 아껴 쓰려면 상대 말을 끝까지 들어야 하니까 경청을 강제하지 않고 유도해.

## 7-3. 대화 책장

지난 대화의 어록·요약을 책 형태로 모아 보여주는 아카이브 (참고: 풀밭, 민음사 책장 앱). 결혼 라인의 "대화 기록이 프로필"이라는 방향과 직접 연결된다.

> 상세 목업 이미지는 하위 페이지 재미요소 참고.
